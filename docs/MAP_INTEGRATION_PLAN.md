# MAP Integration Plan

## 1. Existing Mapping Implementation
- `client/src/components/maps/PlaceholderMap.tsx` – static SVG placeholder used in `RoutePlannerPage`.
- No Leaflet or Geoapify integration currently.
- No map-related services in the backend (`server/src/services` is empty for mapping).
- Environment variables for Geoapify tiles and API keys are not defined yet.

## 2. Goals
1. Replace the placeholder with an **interactive Leaflet map** using **React‑Leaflet**.
2. Use **Geoapify tile layer** for map basemap.
3. Provide reusable map component (`InteractiveMap`) that supports:
   - Centering on a set of coordinates.
   - Rendering markers for stops.
   - Rendering a polyline for the optimized route.
   - Exporting the current view for further UI integration.
4. Create a utility for generating **Google Maps URLs** (separate task).
5. Add map component to all pages that require a map (currently `RoutePlannerPage`).

## 3. Required Dependencies
- `leaflet` (already installed).
- `react-leaflet@4.1.0` (installed).
- Leaflet CSS import (e.g., in `client/src/index.tsx` or component).

## 5. Data Flow
1. Frontend fetches optimized route (already done via `useOptimization`). The result contains an array of stop coordinates.
2. `InteractiveMap` receives `stops: {lat:number, lng:number}[]` and optional `routePath: {lat:number,lng:number}[]`.
3. Component creates `Marker` for each stop and a `Polyline` for the route.
4. Map view automatically fits bounds covering all markers.
