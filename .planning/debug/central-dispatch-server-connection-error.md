# Debug Session: Unable to communicate with the central dispatch server

## 1. Problem Statement & Trigger
User received the error:
`"Unable to communicate with the central dispatch server. Please check your internet connection."`

## 2. Code Trace & Root Cause Analysis
1. In `client/src/utils/errorUtils.ts`:
   ```typescript
   if (lower.includes('network error') || lower.includes('econnaborted') || lower.includes('timeout')) {
     return 'Unable to communicate with the central dispatch server. Please check your internet connection.';
   }
   ```
2. In `client/src/api/client.ts`:
   - An Axios response error interceptor calls `getFriendlyErrorMessage(error)`.
   - Any raw network failure (e.g. `ERR_CONNECTION_REFUSED` when the backend is offline) gets converted into this user-facing string: `"Unable to communicate with the central dispatch server. Please check your internet connection."`.
3. In `client/vite.config.ts`:
   - Vite reverse-proxies `/api` and `/socket.io` to `http://127.0.0.1:5004`.
4. Process Inspection:
   - Port 5004 had no active process listening before this investigation.
   - When the user opened the browser or clicked an action, the browser could not establish a TCP connection to `127.0.0.1:5004`.

## 3. Verification & Resolution
1. Checked MongoDB service: Running (`MongoDB Server (MongoDB)`).
2. Checked Backend Startup:
   - Ran `node server/src/index.js`
   - Output:
     `[MongoDB] Connected to database: smartroute (127.0.0.1)`
     `[Server] SmartRoute backend running on port 5004 (development)`
     `[Server] API v1 base: http://localhost:5004/api/v1`
3. Tested Endpoint:
   - `curl.exe http://localhost:5004/healthz` ➔ returned `{"success":true,"status":"OK"}`.
4. Solution:
   - Run both server and client using the monorepo root command:
     `npm run dev`
   - Or individually:
     - Terminal 1: `npm run dev:server` (starts Express + Socket.IO on port 5004)
     - Terminal 2: `npm run dev:client` (starts Vite React on port 5173)
