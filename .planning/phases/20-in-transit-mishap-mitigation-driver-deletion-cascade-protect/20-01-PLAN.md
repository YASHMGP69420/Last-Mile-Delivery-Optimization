<objective>
Implement the server-side pre-deletion operational resource guards, detailed 409 conflict detection, and atomic orphan recovery cascade service. Ensure that deleting a driver or toggling driver status while an active route or shift is running returns actionable route metadata (`409 ACTIVE_OPERATION_CONFLICT`). When `forceReassign=true` is supplied, execute an atomic transaction rescuing uncompleted deliveries to `READY` pool with `'Urgent'` priority, preserving completed delivery Proof of Delivery (POD) evidence intact, force-closing driver shifts, cancelling the active route, unlinking vehicle assignments, resetting vehicle availability, logging audit events, and broadcasting real-time multi-channel alerts via Socket.IO and SystemNotification.

Purpose: Protect in-transit freight from being orphaned without dispatcher awareness and guarantee data integrity across consignments, routes, shifts, and vehicles during driver mishaps.
Output: `mishapRecoveryService.js`, enhanced `resourceGuardService.js`, updated `adminController.js`, `routeController.js`, `socketService.js`, and integration tests in `server/tests/phase20_mishap_guards.test.js`.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin Client -> REST API | Untrusted input parameters (forceReassign, reason, status) cross Express router into admin controllers |
| Controller -> Mongoose DB | Multi-collection state transitions executed across Deliveries, Routes, Shifts, Vehicles |
| Server -> Socket.IO Clients | Real-time events pushed to management and tracking rooms |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-20-01 | Elevation of Privilege | adminController.js | critical | mitigate | Enforce authorize(ROLES.ADMIN) on deleteUser and updateUserStatus endpoints so only administrators can trigger forceReassign cascade overrides. |
| T-20-02 | Denial of Service | resourceGuardService.js | high | mitigate | Pre-deletion interlock halts user deletion if an active shift or route exists, preventing stranded consignments unless forceReassign=true is intentionally passed. |
| T-20-03 | Tampering | mishapRecoveryService.js | high | mitigate | Wrap all multi-collection mutations in withTransaction session so delivery rescue, route cancellation, and shift closure succeed atomically or roll back completely on failure. |
| T-20-04 | Information Disclosure | socketService.js | medium | mitigate | Broadcast route:cancelled and deliveries:reassigned events only to authorized 'management' and target 'route:${routeId}' rooms. |
| T-20-SC | Tampering | npm dependencies | high | mitigate | Package legitimacy gate verified in RESEARCH.md: no new external packages installed; existing vetted dependencies (mongoose, socket.io, express) used. |
</threat_model>
