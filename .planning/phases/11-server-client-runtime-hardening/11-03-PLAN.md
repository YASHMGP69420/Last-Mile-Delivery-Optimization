## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Reverse Proxy / Internet → Express `trust proxy` | Untrusted `X-Forwarded-For` and `X-Forwarded-Host` headers enter rate-limit and CORS checks |
| Browser → Helmet Security Headers | Served HTML/API responses govern script execution, popup OAuth isolation, tile/font origins, and HTTPS upgrade behavior |
| Container Orchestrator → Process Lifecycle | `SIGTERM`/`SIGINT` signals and `/healthz` + `/readyz` probes govern zero-downtime traffic drain |
| Browser Routes → `SERVE_CLIENT=true` SPA Fallback | Arbitrary GET paths could shadow `/api/*`, `/socket.io/*`, or missing static assets if order is wrong |
