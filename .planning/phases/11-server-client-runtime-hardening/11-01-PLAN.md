<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Process Environment → Server Boot | Untrusted/misconfigured env vars (`JWT_SECRET`, `MONGODB_URI`, `TRUST_PROXY`, `CLIENT_ORIGIN`) enter Node runtime |
| Cross-Origin Client → Express / Socket.IO | Browser `Origin` and proxy `Host`/`X-Forwarded-Host` headers cross into CORS allowlist evaluation |
| Server → MongoDB Atlas / Geoapify API | Outbound database connection options and external routing API credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Elevation of Privilege / Spoofing | `server/src/config/env.js` (`JWT_SECRET`, `JWT_REFRESH_SECRET`) | critical | mitigate | `validateProductionEnv()` rejects missing, `< 32` char, or committed dev/CI/example default secrets in `NODE_ENV=production` and skips dotenv loading in production |
| T-11-02 | Information Disclosure / CSRF | `server/src/config/cors.js` (`parseAllowedOrigins`, `createCorsOptionsDelegate`) | high | mitigate | Strip trailing slashes, omit localhost origins in `NODE_ENV=production` unless explicitly configured, and enforce exact normalized origin or same-request-host match under `SERVE_CLIENT=true` |
| T-11-03 | Denial of Service | `server/src/config/db.js` (`connectDB`) | medium | mitigate | Set `autoIndex: env.NODE_ENV !== 'production'` to avoid blocking production index builds on boot and `serverSelectionTimeoutMS: 12000` for Atlas failover |
| T-11-04 | Tampering / Spoofing | `server/src/config/env.js` (`parseTrustProxy`) | high | mitigate | Reject `TRUST_PROXY=true` boolean wildcard; only permit explicit integer hop count or `'false'`/`'0'` |
| T-11-SC | Tampering | npm installs | low | accept | Zero new npm packages introduced in Phase 11; uses existing verified workspace lockfile packages |
</threat_model>
