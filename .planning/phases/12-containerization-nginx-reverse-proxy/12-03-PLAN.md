<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public Client -> Nginx Edge (`:80`) | Untrusted HTTP/WebSocket traffic enters reverse proxy before reaching Express/Socket.IO |
| Compose Network -> MongoDB (`mongo:27017`) | Database traffic must stay isolated to internal Compose bridge network with no host port exposure |
| Operator Environment -> `docker-compose.yml` | Runtime JWT, OAuth, and OTP secrets enter container environment at `compose up` |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-06 | Spoofing / Tampering | `deploy/nginx/default.conf` | high | mitigate | Strip `server_tokens off`, forward accurate `X-Real-IP`, `X-Forwarded-For`, `X-Forwarded-Proto`, and `$http_host` to `app:5004` (`TRUST_PROXY=1`) so `express-rate-limit` v7 and `isSameRequestHost()` enforce per-client IP limits and origin checks |
| T-12-07 | Information Disclosure | `docker-compose.yml` (`mongo` & `app`) | critical | mitigate | Omit host `ports` on `mongo:6.0` and `app:5004`, publish only `nginx` `:80`, and require `${JWT_SECRET:?...}` / `${JWT_REFRESH_SECRET:?...}` env substitution with zero committed defaults |
| T-12-08 | Denial of Service | `deploy/nginx/default.conf` & `docker-compose.yml` | medium | mitigate | Set `client_max_body_size 12m`, `/socket.io/` `proxy_read_timeout 86400s` + `proxy_buffering off`, `init: true`, and `stop_grace_period: 15s` (above Node's 10s drain timeout) to prevent large CSV drops, 60s WebSocket disconnects, and ungraceful `SIGKILL` terminations |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Pin official upstream image tags (`nginx:1.27-alpine`, `mongo:6.0`) and reuse Plan 12-02's `package-lock.json`-locked app build |
</threat_model>
