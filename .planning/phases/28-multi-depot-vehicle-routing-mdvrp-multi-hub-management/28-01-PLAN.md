## STRIDE Threat Register

|-----------|----------|-----------|----------|-------------|-----------------|
| T-28-01 | Elevation of Privilege | /api/v1/hubs routes | high | mitigate | Protect routes with JWT auth and authorize(ROLES.ADMIN, ROLES.FLEET_MANAGER) middleware; reject driver and anonymous requests |
| T-28-02 | Tampering | Hub coordinates & code input | medium | mitigate | Validate latitude (-90 to 90), longitude (-180 to 180), and trim/uppercase unique code checks to prevent geo-corruption |
| T-28-03 | Denial of Service | deleteHub / toggleHubActive | high | mitigate | Enforce cascade guards rejecting deletion or deactivation of canonical hub or hubs with active vehicle assignments |
| T-28-04 | Information Disclosure | Hub contactPhone & address | low | accept | Hub locations are operational logistics centers shared across authorized fleet personnel |
| T-28-SC | Tampering | npm installs | high | mitigate | Package legitimacy gate verified, no new npm dependencies required |
