## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0B0C0E | Obsidian-950 dark canvas background (#F4F4F5 in light mode) |
| Secondary (30%) | #121417 | Obsidian-900 card surfaces, header bar, navigation bar, drawers |
| Accent (10%) | #10B981 | Emerald-500 primary action buttons and active indicators |
| Destructive | #EF4444 | Error-500 stop failure confirmation and offline warning pill |

Accent reserved for: Primary action buttons (`Mark Arrived`, `Complete Delivery`, `Dispatch Operational Batch`), active bottom navigation icon highlight, and live connected WebSocket status indicator.

Semantic warning / demo color: #F59E0B (Amber-500) reserved exclusively for:
- Sticky top demo indicator banner (`"Demo Driver Session — Simulated Handheld"`)
- Demo entity badge tag (`[Demo]`) in driver/vehicle selection lists
- WebSocket `Reconnecting...` status pill

| Empty state heading | No Active Route Assigned |
| Empty state body | You currently have no dispatches assigned. When central dispatch assigns a route, it will automatically appear here. |
| Error state (Cross-Boundary Dispatch) | Cross-Environment Assignment Prohibited: Demo dispatchers can only assign simulated demo drivers and OD02-DEMO-* vehicles. Select a demo driver or switch accounts. |
| Error state (Network Offline) | Connection Interrupted: Handheld is offline. Stop changes will sync automatically when signal is restored. |
| Destructive confirmation | Report Stop Failure: Confirm that stop [OrderRef] cannot be delivered. Unfinished items will be rescued to dispatch triage. |
