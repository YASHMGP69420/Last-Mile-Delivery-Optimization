## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dispatcher Client → REST API (`PUT /api/v1/vehicles/:id`) | Management operations changing vehicle availability and recording maintenance notes. |
| Dispatcher Client → WebSocket Gateway (`telemetry:request_ping`) | Real-time trigger requesting remote driver GPS refresh. |
| Server → Driver Handheld Socket Room (`driver:${id}`) | Pushed ping request commanding mobile device to acquire and transmit GPS. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-01 | Elevation of Privilege | `PUT /api/v1/vehicles/:id` | high | mitigate | Enforce role-based access control via `authorize(ROLES.ADMIN, ROLES.FLEET_MANAGER)` so drivers or unauthenticated callers cannot alter vehicle status. |
| T-23-02 | Business Logic Tampering | `vehicleController.updateVehicle` | high | mitigate | Enforce operational safety guard blocking transition of `IN_TRANSIT` vehicles to `MAINTENANCE` with HTTP 409 ACTIVE_OPERATION_CONFLICT. |
| T-23-03 | Spoofing / Elevation of Privilege | Socket Gateway (`telemetry:request_ping`) | medium | mitigate | Check `MANAGEMENT_ROLES` in `socketAuth.js` before executing ping; reject unauthorized socket clients with error ack. |
| T-23-04 | Tampering / Stored XSS | `maintenanceNotes` input & display | medium | mitigate | Sanitize and trim `maintenanceNotes` in controller and ensure React auto-escaping prevents script injection on bento cards. |
| T-23-SC | Tampering | npm packages | high | mitigate | No new npm packages installed; all features build on verified React, Leaflet, and Socket.IO dependencies. |
