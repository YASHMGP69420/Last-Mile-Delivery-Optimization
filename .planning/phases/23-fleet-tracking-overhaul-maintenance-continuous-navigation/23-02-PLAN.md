## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Driver Handheld → External Google Maps Application | Native URI intent scheme (`https://www.google.com/maps/dir/?api=1...`) opening turn-by-turn navigation. |
| Server → Driver Handheld Socket (`telemetry:request_ping`) | Server prompts handheld device to trigger GPS hardware acquisition. |
| Telemetry Data → Leaflet DivIcon DOM | Unsanitized driver name or telemetry strings rendered directly into DOM. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-23-05 | Denial of Service | `buildContinuousNavigationUrl` | medium | mitigate | Enforce safe waypoint slicing (`maxWaypoints = 15`) to prevent URL truncation or intent crash when routes contain dozens of deliveries. |
| T-23-06 | Tampering / XSS | `createDriverIcon` (`markerIcons.ts`) | medium | mitigate | Enforce `escapeHtml(driver.name)` before interpolating strings into Leaflet HTML template literal. |
| T-23-07 | Information Disclosure | Coordinate string formatting | low | mitigate | Use `encodeLatLng` with fixed 6-decimal-place precision (~0.1m) to avoid floating-point representation anomalies in external navigation links. |
| T-23-SC | Tampering | npm packages | high | mitigate | No new npm packages installed; relies strictly on existing Leaflet and React dependencies. |
</threat_model>
