<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Unauthenticated client -> `POST /api/v1/auth/demo-login` | Public endpoint accepts `{ role }` from anonymous login page visitors and mints JWT sessions strictly for `isDemoData: true` showcase accounts |
| Demo showcase dataset <-> Real production data & `bootstrapAdmin` | Shared MongoDB collections hold both `isDemoData: false` production records and `isDemoData: true` showcase records |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-quick-01 | Elevation of Privilege | `authController.demoLogin` / `demoDataService.ensureDemoShowcaseUser` | critical | mitigate | Allowlist strictly `{ ADMIN, FLEET_MANAGER, DRIVER }` mapped to fixed `demo.*@smartroute.local` addresses; enforce `user.isDemoData === true` and reject `isDemoData !== true` with `403 DEMO_USER_ISOLATION_VIOLATION` so real accounts are never accessed |
| T-quick-02 | Elevation of Privilege / Spoofing | `bootstrapAdmin` & `auth/login` | high | mitigate | Keep `bootstrapAdmin` scoped to `{ role: ADMIN, isDemoData: false, active: true }` so `demo.admin@smartroute.local` never blocks or alters production admin bootstrap; generate random 32-char hex password hashes for demo admin/manager (`demoPasswordSeed`) instead of weak hardcoded passwords |
| T-quick-03 | Denial of Service / Abuse | `POST /api/v1/auth/demo-login` | medium | mitigate | Protect `/demo-login` with `authRateLimiter` (30 req / 15 min per IP) and handle concurrent auto-import race (`DEMO_DATA_ALREADY_LOADED`) idempotently |
| T-quick-04 | Tampering / Data Pollution | `DemoDatasetPanel` & `deleteDemoDataset` | medium | mitigate | Tag every auto-imported showcase user/driver/vehicle/delivery/batch with `isDemoData: true` and expose explicit `DEMO` badges in headers so all showcase data is removable in one click via `DELETE /api/v1/admin/demo-data` |
| T-quick-SC | Tampering | npm installs | low | accept | No new npm packages introduced; existing verified dependencies only |
</threat_model>
