       - Set `WORKDIR /app` and `ENV NODE_ENV=production PORT=5004 SERVE_CLIENT=true`.

       - Install production server dependencies only and purge npm cache: `RUN npm ci --omit=dev --workspace=server --include-workspace-root && npm cache clean --force`.
       - Copy server code and built SPA assets owned by non-root `node`:
         `COPY --chown=node:node server/ ./server/`
         `COPY --from=client-builder --chown=node:node /app/client/dist ./client/dist`

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Build Arguments -> Image Layer History | Docker `ARG` values and builder `ENV`s are persisted in OCI image metadata/history (`docker history`) |
| Container Process -> Host Kernel / Filesystem | Compromised Node.js process runs inside container filesystem with UID permissions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-12-03 | Information Disclosure | `Dockerfile` (`client-builder`) | critical | mitigate | Scope only public `VITE_*` `ARG`s to `client-builder`; never pass `JWT_SECRET`, `JWT_REFRESH_SECRET`, `MONGODB_URI`, `GEOAPIFY_SERVER_API_KEY`, or SMTP/SMS secrets as Docker build `ARG`s |
| T-12-04 | Elevation of Privilege | `Dockerfile` (`runtime`) | high | mitigate | Set `--chown=node:node` on copied app artifacts and switch to unprivileged `USER node` before `CMD ["node", "server/src/index.js"]` |
| T-12-05 | Tampering / Denial of Service | `Dockerfile` (`HEALTHCHECK` & PID 1) | medium | mitigate | Use exec-form `CMD ["node", "server/src/index.js"]` so `SIGTERM` reaches Node directly for graceful shutdown, and native Node 20 `fetch('/readyz')` `HEALTHCHECK` without installing extra `curl` attack surface |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | Deterministic `npm ci` inside both `client-builder` and `runtime` stages using verified root `package-lock.json` |
</threat_model>
