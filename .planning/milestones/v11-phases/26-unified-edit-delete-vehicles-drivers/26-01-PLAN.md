# Plan 26-01: Driver & Vehicle Edit and Delete Lifecycle Operations with Cascade Protection

## Purpose
Provide complete administrative lifecycle management (edit and delete) for drivers and fleet vehicles in `DriversPage.tsx` and `FleetsPage.tsx`, backed by secure backend endpoints, active operation guards (`409 ACTIVE_OPERATION_CONFLICT`), mishap cascade recovery, confirmation dialogs, and real-time socket updates.

## Tasks

<task type="auto">
  <name>Task 1: Backend Driver & Vehicle CRUD Operations (server/src)</name>
  <files>
    server/src/routes/driverRoutes.js
    server/src/controllers/driverController.js
    server/src/controllers/vehicleController.js
  </files>
  <action>
    1. In `server/src/routes/driverRoutes.js`:
       - Register `router.delete('/:id', authorize(ROLES.ADMIN, ROLES.FLEET_MANAGER), driverController.deleteDriver);`.
    2. In `server/src/controllers/driverController.js`:
       - Enhance `updateDriver`:
         - Accept `name`, `email`, `phone`, `licenseNumber`, `availability`, `rating`.
         - When `name`, `email`, or `phone` is updated: find linked `User` (`driver.userId`) and update its `name`, `email`, and `phone`.
         - Validate email uniqueness on `User` and `licenseNumber` uniqueness on `Driver` (excluding the current entity).
         - Emit `driver:updated` socket event to dispatch rooms.
       - Implement `deleteDriver`:
         - Find driver by ID (throw 404 if not found).
         - Execute `assertNoActiveDriverOrVehicleOperations({ driverIds: [driver._id], actionLabel: 'delete driver' })`.
         - If conflict arises and `req.query.forceReassign === 'true'` or `req.body.forceReassign === true`:
           - Invoke `recoverDriverMishapCascade({ driverId: driver._id, actor: req.user, reason: 'DRIVER_ACCOUNT_DELETED' })`.
         - If driver is paired to a vehicle, unpair cleanly: `await Vehicle.findByIdAndUpdate(driver.assignedVehicleId, { assignedDriverId: null });`.
         - Remove `Driver` record and associated `User` record (`await Driver.findByIdAndDelete(driver._id); await User.findByIdAndDelete(driver.userId);`).
         - Emit `driver:deleted` socket event to dispatch rooms.
         - Return `{ success: true, message: 'Driver deleted successfully' }`.
    3. In `server/src/controllers/vehicleController.js`:
       - In `deleteVehicle`: support query parameter `permanent=true` for removing vehicles from DB when not in transit, while preserving soft-retire (`availability = RETIRED`) as default safe behavior.
       - Emit `vehicle:deleted` socket event.
  </action>
  <verify>
    npm --prefix server test -- server/tests/driver_vehicle_crud.test.js
  </verify>
  <done>
    Backend driver routes support PUT /api/v1/drivers/:id (full profile and user sync) and DELETE /api/v1/drivers/:id (with 409 conflict and forceReassign mishap rescue), and vehicles support permanent or soft deletion.
  </done>
</task>
