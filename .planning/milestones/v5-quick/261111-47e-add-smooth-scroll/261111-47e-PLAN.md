<task type="auto">
  <name>Task 2: Create reduced-motion smooth-scroll utilities and ScrollManager for routes and anchor links</name>
  <files>client/src/utils/smoothScroll.ts, client/src/components/common/ScrollManager.tsx, client/src/App.tsx</files>
  <action>
    1. Create `client/src/utils/smoothScroll.ts` with pure browser helpers (no wheel hijacking or external scroll libraries per `UI-SCR-05`):
       - `prefersReducedMotion(): boolean` — checks `typeof window !== 'undefined' && typeof window.matchMedia === 'function' && window.matchMedia('(prefers-reduced-motion: reduce)').matches`.
       - `getScrollBehavior(preferred: ScrollBehavior = 'smooth'): ScrollBehavior` — returns `'auto'` when `prefersReducedMotion()` is true, otherwise `preferred`.
       - `isInsideLeafletMap(element: Element | null): boolean` — returns `Boolean(element?.closest('.leaflet-container'))`.
       - `smoothScrollToTop(container?: HTMLElement | null, behavior: ScrollBehavior = 'smooth'): void` — resolves `getScrollBehavior(behavior)` and scrolls `container.scrollTo({ top: 0, behavior: resolved })` if `container` is provided, else `window.scrollTo({ top: 0, left: 0, behavior: resolved })`.
       - `smoothScrollToElement(target: HTMLElement | string, options?: { block?: ScrollLogicalPosition; behavior?: ScrollBehavior }): boolean` — if `target` is a string starting with `#`, extract the decoded ID (`decodeURIComponent(target.slice(1))`) and look it up safely via `document.getElementById(id)` (never pass untrusted hash strings into `document.querySelector`); if `target` is an `HTMLElement`, use it directly. Return `false` if missing or `isInsideLeafletMap(el)` is true. Otherwise call `el.scrollIntoView({ behavior: getScrollBehavior(options?.behavior ?? 'smooth'), block: options?.block ?? 'start', inline: 'nearest' })` and return `true`.
    2. Create `client/src/components/common/ScrollManager.tsx`:
       - Inside `ScrollManager`, read `{ pathname, hash }` from `useLocation()`.
       - In a `useEffect` keyed on `[pathname, hash]`: if `hash` is non-empty (and length > 1), schedule `requestAnimationFrame(() => smoothScrollToElement(hash))` and cancel on cleanup; otherwise reset the primary scroll container (`document.querySelector<HTMLElement>('[data-scroll-container="primary"]')`) and `window` to top with `behavior: 'auto'` so route transitions start cleanly at the top without conflicting with `PageTransition`.
       - In a second `useEffect`, attach a delegated `click` listener on `document` for `a[href^="#"]` links: ignore default-prevented clicks, modifier-key clicks, empty `"#"`, links with `data-no-smooth-scroll`, or links inside `.leaflet-container`; if a valid target element exists for the hash, prevent default, call `smoothScrollToElement(href)`, and update `window.history.replaceState(null, '', href)` so anchor navigation stays smooth and URL-synced.
       - Return `null`.
    3. Update `client/src/App.tsx` to import `ScrollManager` from `./components/common/ScrollManager` and render `<ScrollManager />` inside `<BrowserRouter>` right above `<Routes>`.
  </action>
